# Практическая работа 2. Вариант 8

**Вариант 8:** X = MT, Y = MS (только `order_status = 'delivered'`).

- A -- `product_id` товаров, купленных клиентами штата MT
- B -- `product_id` товаров, купленных клиентами штата MS

Запуск: `psql -X -h localhost -U postgres -d olist -v ON_ERROR_STOP=1 -f lab02/lab02.sql`
(последний результирующий запрос скрипта перед пунктом 9 выводит все числа для таблицы ниже).

## Мощности

| Величина | count(*) | Значение |
| --- | --- | --- |
| A (уникальных product_id) | `a_distinct` | _<857>_ |
| B (уникальных product_id) | `b_distinct` | _<653>_ |
| A ∪ B (UNION) | `union_cnt` | _<1414>_ |
| A ∪ B (UNION ALL) | `union_all_cnt` | _<1510>_ (= a_rows + b_rows) |
| A ∩ B (INTERSECT) | `intersect_cnt` | _<96>_ |
| A − B (EXCEPT) | `a_minus_b` | _<761>_ |
| B − A (EXCEPT) | `b_minus_a` | _<965>_ |

## Вывод о дубликатах

- `A` и `B` как запросы возвращают мультимножества: `count(*)` больше `count(DISTINCT product_id)`, потому что один товар встречается в нескольких позициях заказов.
- `UNION ALL` даёт `a_rows + b_rows` строк, `UNION` — только уникальные значения; разница складывается из повторов внутри A, внутри B и товаров, общих для A и B.
- `UNION`, `INTERSECT`, `EXCEPT` возвращают множество; `UNION ALL`, `INTERSECT ALL`, `EXCEPT ALL` и обычный `SELECT` — мультимножество.
- Объединение и пересечение коммутативны (проверка симметрической разности даёт 0), разность — нет: `A − B ≠ B − A`.
- Пересечение через `EXISTS` совпадает с `INTERSECT` только вместе с `DISTINCT`; без него появляются повторы (п. 8 скрипта).

## Контрольные вопросы

1. **Почему UNION обычно дороже UNION ALL?** UNION должен удалить дубликаты — для этого нужны сортировка или хеширование всего результата. UNION ALL просто дописывает строки одного запроса к другому.
2. **Почему отсутствие ORDER BY делает неверным вывод о «порядке» кортежей?** Отношение — неупорядоченное множество кортежей; без ORDER BY СУБД вправе вернуть строки в любом порядке (он зависит от плана, индексов, параллелизма и может меняться), поэтому порядок не несёт информации.
3. **Чем множество отличается от мультимножества?** В множестве каждый элемент встречается не более одного раза; в мультимножестве у элемента есть кратность, и одинаковые элементы считаются отдельно.
